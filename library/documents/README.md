# Documents locaux

Déposer ici uniquement les documents que vous êtes autorisé à utiliser. Ils sont ignorés par Git par défaut.

Pour déclarer un fichier comme disponible, créer une copie de la notice du catalogue et renseigner :

- `content_status` à `excerpt_provided` ou `full_text_provided` ;
- `local_path` relatif à la racine du projet ;
- `sha256` réel du fichier ;
- les pages ou clauses couvertes si seul un extrait est présent ;
- la provenance et les restrictions d'usage.

Une notice sans fichier ni empreinte doit rester `metadata_only`.
